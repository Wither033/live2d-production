# Live2D 角色制作与面捕

先做出一版能跟着人转头、眨眼、张嘴的角色，再修最影响表现的细节。最终交付包含可编辑的素材与工程、从该工程实际导出的运行时包，以及面捕接入结果。用户只要某一步时，终点就是那一步。

## 从手里已有的东西开始

| 用户给了什么 | 第一个动作 |
| --- | --- |
| 文字设定 | Astra 提炼识别特征、画幅和表演需求，再生成可拆的中性立绘。 |
| 一张 PNG 或散件 | 把用户指定原图定为母图。先列运动部件与遮挡关系；现有完整零件直接使用，只补会露出的缺口。 |
| 分层 PSD | 在 Photoshop 区分可编辑母档和载入副本；已有合格图层不重绘，接续网格与绑定。 |
| `.cmo3` / `.can3` | 从用户指定的最新保存版和项目阶段记录接续，在工作副本修补。不要按文件名里的 `final` 选源。 |
| `.model3.json` / VTS 已装模型 | 从运行时包、动作或面捕设置开始。只改运行时的成果据实命名；要改底层网格需对应可编辑工程。 |
| 只要说明、制订方案、制作技能或要求暂停 | 不启动制作软件、接管桌面、开摄像头或恢复定时器。 |

**分清两个 PSD 终点。** “只给我能导入的 PSD”在 Photoshop 交付载入副本即止；“只做到导入 Cubism”由同一名 Terra 导入副本，确认中性显示，保存 `.cmo3` 即止，不继续绑定。若用户只说“做到载入 PSD”，上下文仍无法区分时，只问交付文件还是实际导入。

## 谁指挥，谁操作

桌面步骤需要 Windows、宿主提供的原生 Computer Use，以及本阶段使用的软件。只查 PSD 或导出包时，附带的只读脚本只需 Python 3.9+。

- **Astra 根（`gpt-6-astra`）**：定角色和动作范围、选择母图与版本、组织拆件、给出验收标准，集成 PSD、工程、动作、运行时和使用说明。技能不切换根模型；要求严格使用 Astra 时，从 Astra 主会话调用，不把其他模型标成 Astra。
- **Terra ultra（`gpt-6.1-terra` / `ultra`）**：承担以图形界面为主的 Photoshop、Cubism 和 VTube Studio 任务。一次仅一名 GUI 操作者；能复用就续用，从当前窗口确认应用与工作副本。用户亲自操作某一步时，交还桌面，该步骤不并行输入。
- 生图走 `$imagegen`；文件对齐、打包、曲线和校验优先用合适的脚本或公开接口。Astra 可直接完成这些工作；确需独立非 GUI 子任务时默认 `gpt-6.1-sol`。禁用 Luna，不用 Terra 做纯脚本、文案或普通检索。派发方式与恢复条件见[桌面交接](references/desktop-handoff.md)。

## 工序与交接物

| 工序 | 谁做、留下什么 | 进入下一步的依据 |
| --- | --- | --- |
| [设定与生图](references/concept-to-master.md) | Astra 定设定卡，用内置生图工具制作立绘；留母图、候选、完整提示词与参考用途。 | 中性正面能保住角色身份；审图、一次实际图生图优化、对照后选版。已有批准立绘直接作为依据。 |
| [Photoshop 拆分与补画](references/photoshop-to-psd.md) | Astra 定[部件运动表](assets/parts-plan.tsv)，Terra 做遮罩、隐藏区补画、组装对齐；保留**拆分母档**与**载入 PSD**。 | 单件移开不露洞；归位后与母图半透明叠看，脸型、眼位、颈衣、轮廓和层次吻合。 |
| [Cubism 网格与绑定](references/rig-and-motion.md) | Terra 导入 PSD，建立 ArtMesh、变形器、剪贴及参数关键形，保存可编辑 `.cmo3`。 | 全开／半闭／闭眼与极端视线、头部正侧与四角、领口和发根在实际模型上连贯。 |
| [物理与动画](references/rig-and-motion.md#制作可播放动作) | Terra 建物理和动画场景；Astra 可制作曲线。保留相应的 `.can3` 或可重建曲线的源文件、导出的动作文件。 | 待机循环无接缝，单次动作回正并交还面捕；嘴部和物理输出不被无关轨道锁住。 |
| [导出、VTS、面捕](references/runtime-to-tracking.md) | 从上一步保存的工程导出 SDK 包，安装至 VTS，设置映射／快捷键，接通摄像头或手机。 | 分开记录文件预检、实模播放和真人校准；未做的环节不算通过。 |

**交接只记一份当前状态。** 沿用项目现有记录：源文件和工作副本的路径、采用的部件与参数、保存到磁盘的改动、已看过的动作与仍有问题的组合、下一步和唯一所有者。按当前角色的画面方向、部件和对象 ID 继续，不套用其他工程的命名。

**按任务终点交付。** 只要求导出且明确不检查，直接导出，保留“未试载”状态。要求整套可面捕模型时，一直推进到真人输入；人不在场时先交付可运行包，明确真人校准仍待完成。已有授权可直接执行，不反复请同意；只用项目内或用户点名的素材。只在用户要求时开续作检查；暂停优先于定时和长期权限。

例如：`使用 $live2d-production，从这张 PNG 制作半身面捕模型。保留原画；基础嘴开合即可，先交一版再加动作。`
