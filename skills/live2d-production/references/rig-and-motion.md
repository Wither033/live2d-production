# 从载入 PSD 到能演的模型

先载入可动件，再做关键形，最后做时间轴。对于已有 `.cmo3`，先读其工程记录，看实际有问题的姿态；不要为增加键数而破坏已经好用的绑定。参数名、网格和变形器都以当前模型为准。

### 网格、层级与遮挡

1. **载入 PSD（建模工作区）**：从文件菜单打开载入 PSD 或拖到建模视图，选择新建或向指定模型重新导入的正确分支。核对画布、模型中性姿态、部件可见性与绘制顺序，再存 `.cmo3` 工作副本。[官方 PSD 载入](https://docs.live2d.com/zh-CHS/cubism-editor-manual/psd-import/)
2. **ArtMesh**：大块衣身、脸底、后发可先自动网格；单独给睑缘、睫毛和嘴线布点，让三角形沿着实际弯折方向，闭合时保住线厚。细发尖、角根、领口要有覆盖和支撑，不盲目把全模型加密。已绑对象只局部修，不全选再自动划网。[自动网格](https://docs.live2d.com/zh-CHS/cubism-editor-manual/mesh-edit/) · [手动编辑](https://docs.live2d.com/zh-CHS/cubism-editor-manual/mesh-edit-manual/)
3. **变形器**：部件文件夹管组织，父变形器管运动继承，绘制顺序管遮挡。身体/呼吸 → 颈部位置 → 头部 Z → 头部 XY，是常用起点，不是固定树。五官、前发、角需共同转向；角保持刚性，发梢物理只挂在相应发片。后发只需跟位置时，可在共同 XY 的弯曲变形器与后发之间插入旋转变形器隔离拉伸；位移过大再收小**后发局部**的 XY 跟随。不要调全头或所有头发的物理倍率。[父子组合](https://docs.live2d.com/zh-CHS/cubism-editor-manual/combintion-of-parent-child-relation/)
4. **眼睛**：虹膜、瞳孔、高光随眼球变形器一起移动，剪贴到**同侧**眼白。上睑闭合时向下移动并逐步改弧形，下睑少量上移，眼白开口随之收窄。全闭线与移动睑缘交接不双线、不透金边；不得纵向压扁虹膜来闭眼。若仍缺半块，沿“原始零件 → PSD 像素 → 网格范围 → 剪贴”找首次缺失的位置。[剪贴蒙版](https://docs.live2d.com/zh-CHS/cubism-editor-manual/clipping-mask/)

### 绑定与物理

**第一条可见绑定怎么做：**在变形器树选头部 XY 外层，参数面板选 `角度 X`；只在该对象尚无键时用 **追加三个键**。在中性正面不动，分别点负、正端的键值，用箭头工具调整该关键形；拖过中间值看脸、耳与发根的相对运动。再做角度 Y 的上下端点与 XY 四角。若已有键，先看缺口再改；自动合成四角会覆盖被选中的角，别覆盖已经手调好的对象。给单眼新增半闭形时选的是该眼睑/遮挡对象和 `眼开合` 中间值，不是头部 XY 或眼球视线层。[加键方法](https://docs.live2d.com/zh-CHS/cubism-editor-manual/edit-parameters/) · [四角合成](https://docs.live2d.com/zh-CHS/cubism-editor-manual/synthesize-corners/)

- 头部 `ParamAngleX/Y/Z`（分别对应 `ParamAngleX`、`ParamAngleY`、`ParamAngleZ`）：先做各轴中性/两端，再看 XY 四角和 Z 叠加。近侧与远侧眼、耳、脸缘、鼻口、前发和角根需要有合理的相对运动，不是把所有东西横移。脖子上缘随下巴，下缘留在领口。仅当实看有塌陷或漏缝时为相应对象补中间关键形；不要重新生成整脸覆盖手调结果。
- 基础面捕绑定：左右独立眼开合 `ParamEyeLOpen/ParamEyeROpen`、视线 `ParamEyeBallX/ParamEyeBallY`、基础嘴开闭 `ParamMouthOpenY`；加轻微身体、呼吸 `ParamBreath`。眉形、笑嘴、换装、手势只在约定范围内做。新模型优先标准 ID；续作保留既有 ID、范围和含义。开眼默认通常为 1，不要把“归中”理解成所有值设 0。[标准参数列表](https://docs.live2d.com/zh-CHS/cubism-editor-manual/standard-parameter-list/)
- 眨眼慢拖 `1 → 0.75 → 0.5 → 0.25 → 0` 再反向；这些是**观察值**，不是必须打的键。在失真的中段选对应睑、眼白或遮挡件修姿态，不动用户的全开／全闭端点。只做基础嘴时，检查闭合无重影、中间不开裂、全开有口腔。头部再叠视线、衣领和发根，避免单轴好看、组合穿模。
- 物理先让**输出参数本身**在负／零／正值有可见形变，发根固定、发梢可动；再在 Cubism 配置头/身体输入、摆锤和输出。实际预览“快速转头 → 停住 → 回中”；按发束自身关键形或相应物理组微调，不同时驱动刚性角。保存到源工程，随正式模型导出。[物理模拟](https://docs.live2d.com/zh-CHS/cubism-editor-manual/physics-operation/)

### 制作可播放动作

`.cmo3` 的**参数关键形**决定一个参数值时部件长什么样；`.can3` 时间轴的**关键帧**决定参数何时取什么值。前者不顺，要修几何；后者生硬，要修节奏和切线。提高 FPS 不会凭空增加好看的中间形。

新建动画工程/场景，放入刚保存的模型作为轨道，设时间基准与工作区。在参数轨道打关键帧，用曲线编辑器处理预备、主动作、停留、回弹和归位。待机的首尾值及进出速度相接；单次动作只写需要接管的参数，结束交还面捕，不把嘴和物理输出写成恒值。只用程序制曲线时，保存重建源，按官方 motion3 结构输出，检查目标 ID、时序、计数与范围，再在实模上播放；如承诺了可编辑 `.can3`，要真实导入并保存该工程。[官方动画菜单](https://docs.live2d.com/zh-CHS/cubism-editor-manual/animation-menu/) · [motion3 格式](https://github.com/Live2D/CubismSpecs/blob/master/FileFormats/motion3.json.md)

动作按实际交付选：待机、点头、摇头、歪头、左右观察、低头致意都是可用例子，不是基础面捕的强制清单。点头可让目光先动，在最低点落闭眼，再稍慢睁眼；摇头第二次幅度衰减；观察先转眼后转头。用**实际运行模型**看节奏，保留代表性端点和中段。只在旧运行时验证的动作要标明基线，不能据此声称新版网格已修好。
